# Continuous Menu Layout

## Goal
Replace the category-selection screen on each location menu with one continuous menu that shows every active category and its available items.

## Changes
- Load active categories and their current Toast items together for Downtown, Suburbs, and Savannah.
- Keep the selected Continuous Bistro Scroll look within the existing Toast brand system: Telegraf type, light-blue background, white menu surface, brown text, red accents, and circular food images.
- Present each category as a clear section heading followed immediately by its items, descriptions, and prices.
- Keep every item linked to its existing SEO-friendly detail page.
- Add compact loading and empty states suitable for the longer menu.
- Preserve the existing category and item URLs for search engines and direct links.

## Responsive behavior
- Desktop and tablet use spacious editorial rows and centered category dividers.
- Mobile uses smaller images, tighter spacing, readable descriptions, and stable price alignment.
