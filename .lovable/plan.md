# Catering Page Redesign

## Goal
Replace the current general catering page with a polished, location-first experience that makes it easy to order catering from any of Toast! All Day's six active locations.

## Page structure
- Keep the existing site header, footer, and overall Toast! branding.
- Refresh the catering introduction with a concise, food-forward headline and one clear path into the location choices.
- Add a responsive six-card location grid for Downtown Charleston, King Street, Mt Pleasant, West Ashley, Summerville, and Savannah.
- Use each location's existing authentic photo, location name, city context, and supplied Toast catering destination.
- Place a prominent **Order Catering Now** button on every card, opening the matching Toast page in a new tab.
- Remove the generic ezCater ordering buttons and unsupported event statistics.
- Retain a concise catering benefits section so visitors understand suitable occasions and menu flexibility without distracting from ordering.

## Experience and quality
- Use the established Telegraf typography, brown text, light-blue surfaces, blue accents, and red emphasis.
- Keep cards compact, polished, and easy to scan on phones, tablets, and desktops.
- Add restrained entrance and image interactions that respect reduced-motion settings.
- Update catering page search copy to include all six service areas.
- Verify all six links, visual layout at desktop and mobile sizes, and the site build.

## Technical details
- Rebuild the existing catering page only, reusing current design-system buttons and optimized location image assets.
- Use responsive image loading and defer below-the-fold imagery where appropriate.
- Preserve the existing `/catering` URL and site navigation links.
